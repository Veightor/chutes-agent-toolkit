- The request body is FLAT — send the request fields at the top level (no `input_args`/`args` wrapper).

## Endpoints

### 1. POST /v1/classify

- Base URL: `https://astroboi-halo4b-guard-alpha.chutes.ai`
- Output content type: `application/json`

Request fields:

- `model` (string, optional) Default: null.
- `query` (string, optional) Default: null.
- `messages` (array, optional) Default: null.

Example call:

cURL:

```bash
curl -X POST "https://astroboi-halo4b-guard-alpha.chutes.ai/v1/classify" \
  -H "Authorization: Bearer $CHUTES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "halo4b-guard-alpha",
  "query": "Your text here",
  "messages": [
    {
      "role": "user",
      "content": "Hello!"
    }
  ]
}'
```

Python:

```python
import os
import requests

api_key = os.environ.get("CHUTES_API_KEY")
if not api_key:
    raise ValueError("Missing CHUTES_API_KEY")

url = "https://astroboi-halo4b-guard-alpha.chutes.ai/v1/classify"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json",
}
data = {
    "model": "halo4b-guard-alpha",
    "query": "Your text here",
    "messages": [
        {
            "role": "user",
            "content": "Hello!"
        }
    ]
}

response = requests.request("POST", url, headers=headers, json=data)
response.raise_for_status()

result = response.json()
print(result)
```
